
# Bank Manager Simulator

A database-driven banking management simulation game built using Python and PostgreSQL.

Players manage a virtual bank, handling customer accounts, deposits, withdrawals, loans, and investments.

The simulation features 15 unique customers with independent financial personalities, salaries, spending habits, and decision-making behaviours.
